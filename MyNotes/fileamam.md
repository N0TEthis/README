### Основы редактирования текста  🍊

---

### Навигация по тексту (Перемещение курсора)

*   **← / →** — перемещение на один символ влево/вправо
*   **↑ / ↓** — перемещение на одну строку вверх/вниз
*   **Ctrl + ← / →** — перемещение по словам (влево/вправо)
*   **Home** — переход в начало текущей строки
*   **End** — переход в конец текущей строки
*   **Page Up (PgUp)** — прокрутка на один экран вверх
*   **Page Down (PgDn)** — прокрутка на один экран вниз
*   **Ctrl + Home** — переход в самое начало документа
*   **Ctrl + End** — переход в самый конец документа
*   **Ctrl + ↑ / ↓** — прокрутка страницы без перемещения курсора (работает в некоторых редакторах)

### Управление файлом и действиями

*   **Ctrl + S** — сохранить документ
*   **Ctrl + Shift + S** — «Сохранить как...» (сохранение копии под другим именем или в другом месте)
*   **Ctrl + O** — открыть файл
*   **Ctrl + N** — создать новый документ
*   **Ctrl + Z** — отменить последнее действие (шаг назад)
*   **Ctrl + Y** или **Ctrl + Shift + Z** — вернуть отмененное действие (шаг вперед)
*   **Ctrl + A** — выделить всё содержимое документа
*   **Ctrl + F** — открыть окно поиска текста
*   **Ctrl + H** — открыть окно поиска и замены текста

### Выделение текста

*   **Shift + ← / →** — выделение по одному символу (влево/вправо)
*   **Shift + ↑ / ↓** — выделение построчно (вверх/вниз)
*   **Ctrl + Shift + ← / →** — выделение по словам (влево/вправо)
*   **Shift + Home / End** — выделение от курсора до начала/конца строки
*   **Shift + PgUp / PgDn** — выделение постранично вверх/вниз
*   **Ctrl + Shift + Home / End** — выделение от курсора до начала/конца документа
*   **Двойной клик мышью** — выделение слова
*   **Тройной клик мышью** — выделение абзаца

### Работа с Tab (Отступы и фокус)

*   **Tab** — добавить отступ в начале строки (красная строка) или переместить фокус к следующему элементу (кнопке, полю или ячейке таблицы).
*   **Shift + Tab** — убрать отступ (сдвиг влево) или вернуться к предыдущему элементу/ячейке.
*   **Ctrl + Tab** — переключение между вкладками (в браузере или программе).
*   **Alt + Tab** — переключение между открытыми окнами Windows. *(Добавлено, так как это часто используемая команда)*

### Горячие клавиши форматирования (если редактор поддерживает)

*   **Ctrl + B** — сделать текст **жирным**
*   **Ctrl + I** — сделать текст *курсивным*
*   **Ctrl + U** — сделать текст <u>подчеркнутым</u>
*   **Ctrl + C** / **Ctrl + Insert** — скопировать выделенный текст/объект
*   **Ctrl + X** / **Shift + Delete** — вырезать выделенный текст/объект
*   **Ctrl + V** / **Shift + Insert** — вставить из буфера обмена
